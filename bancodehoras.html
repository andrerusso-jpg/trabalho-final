Banco de Horas Funcionários

Desenvolvi esse projeto para minha mãe usar no trabalho dela, ela fazia tudo em planilha e queria algo que fosse mais facil de mexer, e que guardasse os dados de forma mais organizada, então eu fiz esse banco de dados para ela usar no seu dia dia no trabalho. Nele ultilizei Java, JavaScript, HTML, CSS, Docker e armazenei em SQL para criar um sistema de controle de horas trabalhadas pelos funcionários.
